## Boundaries and data flow

The route reads the current sample account's five booleans; a switch writes
only to that account's in-memory session and triggers a preview rebuild.
Always on rows are display only. The send decision accepts a template and
the intended recipient's settings and returns a Boolean. The renderer takes
an approved record and, optionally, a validated HTTPS button URL. It has
no mail transport, server call, template database, production setting read,
unsubscribe handler or real action link. The preview buttons are display
samples. No migration or live apply occurred.

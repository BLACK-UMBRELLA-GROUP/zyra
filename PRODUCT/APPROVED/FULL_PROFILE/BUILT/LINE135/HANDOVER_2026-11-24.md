# Line 135 — full profile and shared Profiles card

## Built behavior

The Founder preview now uses one shared details card on Profiles and the full
profile. It has the admitted first photo or warm fallback, the combined public
name and ONE pill, four public fact tiles, Main Guardian and Compatibility
rows. The Compatibility row opens the existing preview page. The fixed card
keeps the same placement in Profiles and the full profile; the latter puts its
current action in the bottom band. The band grows at Larger Text so two-line
buttons remain inside their pills. Fact labels and values wrap between whole
words. A tile takes the full row when any word is wider than its half-width
text room; subsequent tiles move down. Hyphenated places stay intact. V5 keeps
label 11 / value 15, the card width, and the photo floor of 72 pt.

Full profiles show the entry's title: Introduction, Journey request, Journey,
or Profile. Tapping the card advances from details through each admitted
photo and wraps to details. It does not swipe. The options sheet shows Hide,
Report, Block and Cancel. Journey Hide and Block use the existing LOCK 16
confirmation before changing the local preview state. Received-request
Decline uses its existing confirmation. An Introduction keeps its actual
“Put forward by” source and offers Decline and Request a Journey. A Guardian
suggestion appears on the received-request card. Guardian Introduce uses the
locked “Marked…” confirmation text.

Founder sample routes in Journey, requests, Introductions and Profiles use the
new page. Sample Hide and Block remain owner-scoped and are reflected in
Browse and Settings Hidden and blocked, where they can be undone. Sample
Report opens the existing report form and Report sent state without network
transport. Safety and Compatibility callbacks check the owning route and
account. The sample full-profile route is a regular push so iOS edge return
remains available. Existing real-member `SeekerProfileScreen` callers outside
the Founder sample preview are outside this line's sample-only brief.

does not change Profiles swiping, Journey Bio, request limits or the later

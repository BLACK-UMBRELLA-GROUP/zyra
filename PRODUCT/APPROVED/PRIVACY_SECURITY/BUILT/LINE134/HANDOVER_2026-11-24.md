# Line 134 — LOCK 40 privacy and security

## Current state

Settings now opens Hidden and blocked, App lock, and Sign-in & security for
Seeker and Guardian previews. Guardian Settings omits Pause My Profile.
Guardian Advanced keeps the two-year away rule and omits the six-month rule
and the pause suggestion; Seeker Advanced shows both fixed away rules.
The pages use the approved ps00–ps05 and ps07–ps09 words and sample layout.
The phone's native Face ID/passcode sheet supplies ps06 behavior; ZYRA does
not draw its own authentication sheet.

The Hidden and blocked list takes the current sample model's own hidden and
blocked IDs. It never displays a peer's block of this member. A row shows
only first name and date. Show again acts immediately; Unblock requires the
approved confirmation. Neither action sends a notice, restores a Journey or
request, or changes the 30-day wait. Empty lists display the locked empty
section text.

App lock uses the device's existing local authentication service with phone
passcode fallback. Existing enabled users without a saved delay keep
Straight away. A new enable starts at 1 minute. The four delay choices and
the app-switcher and notification-text switches are kept in account-bound
local preferences, never sent to the server. Both privacy switches default
on. The message-text rule yields “New message” when hiding is on; live push
delivery is outside this line. On account change, the lock singleton reloads
the incoming account's cover and delay so an earlier account's choice cannot
leave the new account exposed in the app switcher.

Sign-in & security shows sample devices. The other-device action asks the
native check, removes the two sample other devices and shows the locked
one-device state. Delete my account, Download my data, Sign out all other
devices, and Guardian Make Main request the native check at the action point.
Cancelling or failing leaves preview state unchanged and shows no error
toast for Guardian Make Main. No real sign-out, deletion, export, device
session management, inactivity job or phone installation occurs here.

## Source and data flow

- `SOURCE/lib/dev/zyra_privacy_security_preview.dart` renders the three
  pages from explicit sample inputs and callbacks.
- `SOURCE/lib/dev/zyra_one_journey_concept_shell.dart` routes Settings,
  filters own Hidden/blocked choices, scopes sample device state, and gates
  the four sensitive actions. Its testing hook replaces only the native
  check in the detached preview tests.
- `SOURCE/lib/services/zyra_local_prefs.dart` stores account-bound device
  choices; `zyra_app_lock.dart` applies the delay, switcher cover and native
  authentication. `zyra_notification_privacy.dart` supplies the pure message
  redaction rule.
- `SOURCE/lib/dev/zyra_help_safety_preview.dart` supplies role-specific
  fixed away rows. `SOURCE/ios/Runner/Info.plist` and the Phone access page
  use the approved Face ID purpose sentence.

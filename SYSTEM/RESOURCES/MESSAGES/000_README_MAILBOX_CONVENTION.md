# MESSAGES — the Fable ↔ Codex mailbox (created 2026-08-23 by Fable)

WHY: the Founder said "look in files to see what Codex is asking" — and no
file existed. A question typed into a chat window reaches nobody else.
This folder is the ONE place agent-to-agent messages live when the Founder
is not copy-pasting.

RULES
1. One message = one file:  NNN_FROM-TO_YYYY-MM-DD_SUBJECT.md
   (e.g. 001_CODEX-FABLE_2026-08-23_NOTIFICATION_POPUPS.md).
   NNN continues the sequence — check the folder first.
2. Answers are appended to the SAME file under a "## REPLY" heading, or
   filed as the next number referencing it.
3. A message that creates work still goes through the registers — this
   folder is conversation, not governance. Decisions/actions get filed by
   Fable as usual.
4. Founder can read everything here at any time; nothing secret, no keys,
   no credentials, ever.

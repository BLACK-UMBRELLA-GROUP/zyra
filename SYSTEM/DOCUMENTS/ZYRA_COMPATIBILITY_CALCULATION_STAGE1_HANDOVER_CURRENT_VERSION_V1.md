## 3. Architecture and data flow

The only entry points are research functions invoked by synthetic tests. There are no app buttons, routes, developer toggles or persistence hooks.

Raw typed entry lists → manifest configuration validation → owner evidence/preferences → counterpart answers → independent Hard Requirement exclusions → immutable scoring units → exact overall/category totals.

The adapter alone imports three existing pure metadata libraries: `chapter3_categories.dart`, `zyra_reference_data.dart` and `onboarding_question.dart`. Nested metadata collections are copied and sealed. Other modules import only local research modules. Isolation tests inspect the production Dart/native/configuration import boundary and prohibit network, persistence, clock/random and runtime entry-point dependencies.

Configuration errors take precedence over owner repair, then generic target unavailability, then valid hard exclusion. No failed/excluded state publishes a provisional number. Target unavailability deliberately has no missing-answer diagnostic. These are research types, not approved public messages or a production API/authentication contract.

Raw lists preserve duplicate/type evidence before map/set normalization. The harness rejects a declared lossy representation. It does not fix or prove the production JSON decoder. The boolean entry-evidence marker is a research input assertion, not server proof.

## 6. Arithmetic and Chapter2

Each valid scoring question contributes one available unit. Scalar contribution is 1 / 0.5 / 0; a multi-select averages all validated selected lights within its one unit. BigInt-backed exact fractions preserve raw sums. Overall is sum of earned / sum of available, not an equally weighted category average or a reconstruction from rounded percentages.

Internal patterns distinguish all-Amber Open from equal-mean Green/Red Mixed. Valid zero alignment with positive coverage is distinct from no scoreable data. Empty categories remain present internally; no Plus bands, user-facing exact category values or display rounding are generated.

The import-independent hand-derived oracle covers scalar fractions, 3/4 and 5/6 multi-select examples, unequal-category 1/4 rather than 1/2, and OA228's 100→75 two-question regression. Order invariance and exact category/raw-total reconciliation pass.

Chapter2 retains provisional contribution weight 1 and the current governed conditions: canonical sect matrix/hards; Revert only when target true; preferred-list match/flexibility; governed skip/no-preference; language overlap excluding English-only preferences.

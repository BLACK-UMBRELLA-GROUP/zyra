## 5. Routing: implemented boundaries and gap

| Card | Existing-source destination | Sample destination |
|---|---|---|
| Journey action or movement | Existing Connections → Journeys owner-tab callback | Labelled local destination preview |
| Guardian request/status | Existing Guardian tab callback | Labelled local destination preview |
| Existing onboarding obligation | Existing onboarding callback | Labelled local destination preview |
| Billing, editorial, reflection, guide | No invented live destination/source | Local preview explains owner page and sends/saves nothing |

**Known gap:** this is canonical owner-page routing, not exact Journey/request
deep-linking. The current Dashboard callbacks carry a target enum, not the
required item identity. Destination owner lists load through their existing
flows; exact-item selection/revalidation is not claimed as completed. This is
recorded under OA-ZYRA-287 for the Founder review, rather than silently
constructing invitation, billing or article workflows. No “View all” appears
without a real governed destination. My ZYRA contains no accept/decline,
continue/pause/end, Make Main, remove, checkout or cancellation mutation.

Sample routes deliberately do not open a real Journey with a fictional ID:
an existing developer owner path can create/reuse a test Journey. Samples
therefore open a clear **Destination preview** with owner information and a
Back button. They cannot mutate a real account.

## 6. Truth states

- Successful empty: section omitted; no blank heading.
- Unknown/loading: loading state, never all-clear.
- Unavailable: visible failure/retry, not false empty.
- Failed Updates with earlier rows: **Last known** plus refresh warning.
- Nullable unread: only true shows unread. NULL is never labelled read.
- All-clear: only after complete relevant source health and no current cards.
- Insights unavailable/loading: cannot render sample cards as fresh.
- Honest-empty Insights keeps the exact Founder copy:
  **Insights will grow with your ZYRA experience**
  “ZYRA will only show an Insight when reliable information genuinely supports
  it. We will not guess or fill this page with generic statistics.”

The global source health is conservatively aggregate; a failed source can
show a general warning as well as the specific unavailable section.
Retry in fixed samples is intentionally inert so the selected error example
remains inspectable; retry in Existing sources calls the existing loader.

## 1. Purpose

Governs the ZYRA project within the Black Umbrella Group organisation. Defines how decisions
are made, how work is authorised, and how the project reports upward to Black Umbrella Group.

---

## 2. Project Authority

| Role | Authority |
|------|-----------|
| Lead Architect | Final decisions on architecture, governance, and product scope |
| Black Umbrella Group | Autonomous overnight inspection and reporting |
| ZYRA Development Team | Implementation within approved specifications |

---

## 3. Decision Framework

Requires Lead Architect approval:
- New features added to ZYRA scope
- Changes to architecture or data model
- Changes to this governance document
- Promotion of working drafts to governed documents

Delegated to Development Team:
- Implementation approach within approved spec
- Internal tooling and code organisation

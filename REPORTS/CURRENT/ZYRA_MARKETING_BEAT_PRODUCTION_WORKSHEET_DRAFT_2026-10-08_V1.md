## 2. Reading this worksheet and counting rules

- Row key `Vxx-Bxx` means **variant–beat**, not the master brief number.
  Existing master groups remain V01–V03 = B01, V04–V06 = B02 and V07–V09 = B03.
  Existing optional TikTok/Instagram/Facebook order is unchanged.
- Existing storyboard prose is quoted literally. **C** is exact primary source
  copy referenced by that beat. Hook is explicitly labelled **Hook**, not
  silently treated as Script. **Q** is the existing required visible qualifying
  text. Empty Q means the source assigns no separate qualification at that
  beat, not permission to omit the variant's complete ending/status.
- Quotations remove only the Markdown blockquote marker and its following
  single space, then normalise every whitespace run to one U+0020 and trim.
  Source words, spelling, case, punctuation, contractions and placeholders stay
  unchanged. Line-wrapping is presentation, not a copy rewrite. Source links give
  the original one-based lines in the unchanged pinned file.
- C and Q are counted **separately**. Multiple quoted fragments in one cell are
  joined with one U+0020 for that cell's count; labels, links, Markdown and
  `<br>` separators are not counted.
- A word matches `/[\p{L}\p{N}]+(?:['’][\p{L}\p{N}]+)*/gu`. Letter/number runs
  count; internal straight/curly-apostrophe contractions count as one.
  Hyphens/em dashes separate words; standalone punctuation does not count.
  Literal placeholder names and their instruction words count now, not as
  estimates of future filled text.
- Characters are Unicode code points, `[...normalisedText].length`, including
  spaces, punctuation and brackets. They are not UTF-8 bytes, grapheme clusters,
  glyph widths or lines on a device. Empty text has zero words/characters.
- A **REVIEW** row counts its quoted candidate reference package; it does not
  assert accepted placement. Unassigned lead-ins are retained separately,
  not dropped or invented into another beat.
- **Never add C and Q as spoken copy or estimated runtime.** Q can repeat text
  already in C and remain visually across an ending. B01 beat 4's retained
  C01 is not a second spoken repetition. Hooks are not automatically additional
  narration. Whole Script/Caption totals and unresolved text are separate checks.
  Fragment order here is source-reference order, not new timing/animation
  instructions; especially V05/V06's “and” does not become “then”.
- B01/B03 endings are faithfully carried in C. Q carries the full required
  visible C01 status without asserting a new mandatory ending overlay. Where
  an ending's visual versus spoken treatment is unspecified, that production
  choice remains REVIEW/UNMEASURED; no new display/narration assignment is made.

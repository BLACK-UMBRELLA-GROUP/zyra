FEATURE NAME
ZYRA JOURNEY PHILOSOPHY
Group: 0 — Governing Philosophy

============================================================
PURPOSE
============================================================

This document captures the founding intent behind
the ZYRA Journey system. Every feature decision should
be checked against this philosophy before it is approved.

============================================================
THE CORE STATEMENT
============================================================

ZYRA does not build a platform where people chat.
ZYRA builds a guided marriage journey.

The goal is intentional progression — not maximising
time spent in the app.

============================================================
JOURNEY PURPOSE MAPPING
============================================================

Every step in the ZYRA journey has exactly one purpose.
If a feature cannot answer "what is its purpose here?"
it should not exist.

  STEP                 PURPOSE
  ─────────────────────────────────────────────────────
  Match              → Mutual interest confirmed
  Compatibility      → Should we explore this?
  Salam              → Begin respectfully
  Guided Discovery   → Understand each other
  Family Stage       → Involve guardians and families
  Conversation       → Build the relationship
  Meeting            → Meet appropriately
  Nikah              → The intended destination
  ─────────────────────────────────────────────────────

============================================================
DESIGN PRINCIPLES DERIVED FROM THIS PHILOSOPHY
============================================================

1. INTENTIONAL, NOT ENDLESS
   Every stage ends with a deliberate shared decision.
   Neither party drifts forward. Both choose to continue.

2. STRUCTURE DOES NOT DISAPPEAR
   When Conversation opens, the structured journey
   continues alongside it. AI prompts, milestones, and
   optional questions persist. The experience does not
   suddenly become a standard chat app.

3. ONE JOURNEY AT A TIME
   A Seeker may only be in one active journey.
   This signals seriousness. It creates focus.
   It removes the behaviour of casual parallel chatting.

4. PURPOSE BEFORE FEATURE
   No screen, button, or interaction exists without
   a stated purpose tied back to the Journey Purpose
   Mapping above.

5. MEANINGFUL OVER MAXIMUM
   The Journey is designed so that less time in
   the app but more meaningful time leads to better
   outcomes. Engagement metrics are not the goal.
   Nikah is the goal.
